# RAM STEALIN' SAM

A 3D platform-action prototype built on [madness-engine](https://github.com/h1ddenpr0cess20/madness-engine).

## Run locally

```sh
npm install
npm run dev
```

## Controls

- WASD / arrow keys: move
- Left mouse drag: move toward pointer
- Right/middle mouse drag: orbit camera
- Space: jump
- F: RAM raid (close-range attack)
- Mobile: on-screen jump and RAM raid buttons
- Shift: sprint
- M: mute audio
- Mouse drag on the arena: move toward the pointer

Collect RAM sticks around the plaza and from knocked-out opponents. Carry it to the glowing delivery pad at the data center. The target is 20 RAM delivered.

Collect RAM sticks, raid rival tech workers for their RAM, and deliver enough hardware to the data center.

The player currently uses the engine's `robot` cast member (the Robot Waiter) as a placeholder.

The player's temporary model is the engine's **Robot Waiter** (`madness-engine/characters/robot`).
